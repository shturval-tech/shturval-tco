# Калькулятор TCO Штурвала

Сколько стоит Kubernetes в проде, если считать не только лицензию, но и людей: сборку, обновления, уязвимости, дежурства и простои.

**Открыть калькулятор:** https://shturval-tech.github.io/shturval-tco/

## Что сравниваем

- своя сборка на ванильном Kubernetes;
- своя платформа, разработанная с нуля;
- Штурвал.

Лицензию Штурвала калькулятор не считает. Он показывает, сколько стоит эксплуатация в каждом варианте и какой бюджет высвобождается. Эту сумму можно сравнить со стоимостью лицензии.

## Как пользоваться

1. Укажите число кластеров и worker-узлов, горизонт расчёта, режим поддержки и зарплату инженера.
2. Если нужно точнее, откройте расширенные параметры: рост кластеров, стоимость сотрудника, размеры команд, простои.
3. Посмотрите детализацию по статьям, годам и людям.
4. Запросите подробное ТЭО и расчёт лицензии через форму на странице.

## Методика

Формулы и коэффициенты открыты: их можно проверить на странице и поправить под себя в таблице трудоёмкости. Значения по умолчанию – наши оценки, а не данные вашей компании. Точнее всего расчёт будет на ваших цифрах.

Калькулятор в статусе прототипа: методику и коэффициенты ещё сверяем.

## Как устроено

Одна статическая страница без сервера, расчёт идёт в браузере. Форма заявки открывает письмо в вашей почтовой программе.

Чтобы запустить локально, скачайте репозиторий и откройте `index.html`.

В репозитории лежит собранная версия страницы, которая публикуется через GitHub Pages из ветки `main`.
